### Divergence notes (non-load-bearing)

- Generator is `scripts/gen-programs-seed.ts` (TS, strict-linted), NOT the `scripts/*.js` lenient
  lane the panels nominally suggested — required so it can import the canonical TS `PROGRAMS` and be
  imported by the tsx-run drift test with no CJS/ESM friction. The migration `.sql` CONTENT still
  stays off the lint surface (ESLint only lints .ts/.tsx/.js), honoring 009's intent.
- One-function-per-file (`local/single-declaration`) forced: guards split into `src/data/guards/*`
  (mirrors `src/data/engine/`); `db.ts` inlines the pool init into `query`; the generator's helpers
  are inner arrows.
